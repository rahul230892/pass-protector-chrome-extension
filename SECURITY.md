# Security Policy

## Supported Versions

This project is currently maintained from the `main` branch.

## Reporting a Vulnerability

If you find a security issue, please open a GitHub issue with enough detail to reproduce the behavior. Avoid sharing real PINs or private browsing data in reports.

## Important Limitations

Pass Protector is a lightweight local privacy guard, not a hardened security boundary. Someone with access to your Chrome profile, extension settings, developer tools, or filesystem may be able to bypass or disable it.

For stronger protection, use:

- A separate operating system user account.
- Chrome Guest mode.
- A separate Chrome profile for other people.
- Your operating system lock screen.
