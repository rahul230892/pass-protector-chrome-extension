# Privacy Policy

Pass Protector is a local-only Chrome extension.

## Data Collection

Pass Protector does not collect, sell, transmit, or share personal data.

## Local Storage

The extension stores the following data locally in Chrome:

- Your protected website list.
- A SHA-256 hash of your 4-digit PIN.

Your PIN, protected website list, browsing data, and settings are not sent to any server.

## Permissions

Pass Protector uses Chrome permissions only to:

- Save settings locally.
- Detect whether the current website matches your protected website list.
- Show the lock screen on protected websites.

## Contact

Please open a GitHub issue if you have privacy or security questions.
